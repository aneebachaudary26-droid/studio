# **App Name**: Aneeba Chaudary | Materials Scientist

## Core Features:

- Dynamic Content Rendering: All website content is dynamically rendered from a single, easy-to-edit JSON file, ensuring seamless updates without code changes.
- Modular Section Control: Sections can be individually enabled, disabled, or ordered via the JSON configuration file, allowing for flexible content presentation.
- Interactive Research Timeline: A visually engaging and interactive timeline to showcase academic, research, and industry milestones with detailed entries.
- Publications Management with Advanced Filtering: Display a comprehensive list of publications with filtering capabilities by year, research area, authorship, journal, and keywords.
- Professional Contact Form with Secure Brevo Integration: A robust contact form with input validation, spam protection, and secure email delivery via Brevo API, managed through Firebase Functions to protect API keys.
- AI-Powered Content Refinement Tool: A tool leveraging generative AI to assist in refining and structuring the 'About Me' storytelling section, project descriptions, and publication impact statements, based on input points and keywords.
- Dual Theme Support with Seamless Toggle: Implement both light and dark modes, allowing users to switch themes. The design ensures an excellent visual experience in either mode by default.

## Style Guidelines:

- The color palette is inspired by the meticulous nature of materials science, opting for a sophisticated, technical feel. The primary color is a deep indigo (#4D3A73), providing a strong foundation of professionalism and depth. The background in light mode is a very subtle, desaturated violet-gray (#F4F3F6), offering a clean and elegant canvas, with its dark mode counterpart being a rich charcoal. A contrasting, vibrant but professional blue (#5672DB) serves as an accent, drawing attention to interactive elements and key information, reflecting precision and innovation.
- Headline font: 'Space Grotesk' (sans-serif) to convey a modern, tech-inspired, and scientific look. Body text font: 'Inter' (sans-serif) for superior readability across various screen sizes and a neutral, objective aesthetic, aligning with the research-driven content.
- Utilize sleek, minimalist vector icons with a scientific and technical theme. Avoid overly illustrative or cartoonish designs, focusing instead on clarity, abstract representation of scientific concepts (e.g., molecular structures, gears, beakers), and functionality to enhance the user interface.
- A highly responsive, grid-based layout for all modular sections, emphasizing clean lines and generous negative space to create a 'scientific dashboard' feel. This design ensures optimal content hierarchy, ease of navigation, and a professional appearance on all device sizes.
- Incorporate subtle, performant animations using Framer Motion for smooth page transitions, elegant section reveals on scroll, interactive hover effects on cards and buttons, and a gentle, abstract motion background in the hero section (e.g., polymer chains). Animations are designed to be cinematic and enhance user experience without reducing performance or causing distraction.
